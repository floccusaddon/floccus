# Floccus Local：Windows 本地实时收藏夹同步

## 适用范围

Floccus Local 在同一台 Windows 电脑上的 Chrome 与 Edge 之间同步一个选定的收藏文件夹。按本项目的默认迁移流程，两端都选择“收藏栏／书签栏”，其全部子文件夹、收藏顺序、新增、删除、改名、网址修改和移动都会同步。它不处理标签页、其他收藏夹或跨电脑同步。

数据只保存在 `127.0.0.1` 本机服务和两个浏览器中。服务数据库默认位于 `%LOCALAPPDATA%\FloccusLocal\floccus-local.sqlite3`。

## 安装

解压服务包后，双击根目录中的 `Floccus Local.cmd` 打开中文菜单。菜单可以生成并自动复制配对码、启动服务、设置或取消开机启动，以及显示故障信息；关闭菜单不会停止同步服务。

1. 使用 `local-server\scripts\package-windows.ps1` 在 Node.js 24 LTS 下制作服务包，或解压已经交付的 `floccus-local-service-windows.zip`。固定解压目录，后续在此目录原地升级。
2. 在菜单中选择“启动服务”，再选择“设置／取消开机启动”完成自动启动设置。`scripts` 中的独立脚本保留用于故障排查。
3. 在 Chrome 和 Edge 的扩展管理页分别打开“开发者模式”，将 `floccus-local-v5.10.3-chrome-edge.zip` 解压到两个固定目录，再分别“加载已解压的扩展程序”。不要让两个浏览器共用一个会被移动或删除的临时目录。
4. 每连接一个浏览器前，在菜单中选择“生成配对码（自动复制）”。配对码为一次性、15 分钟有效；Chrome 与 Edge 必须分别生成。
5. 扩展中新建“本机实时同步”配置，地址保持 `http://127.0.0.1:32145`，输入配对码，并将本地文件夹选为收藏栏。默认实时双向、启动补齐和每分钟兜底检查保持开启。

## 从原版 Floccus 迁移

在真实收藏夹上第一次运行前必须完成以下步骤：

1. 分别在 Chrome 和 Edge 导出当前收藏 HTML；在原版 Floccus 中导出配置。不要把 GitHub 上的某次历史提交当作当前浏览器数据。
2. 关闭两个浏览器中会修改收藏栏的其他同步来源，包括原版 Floccus 的对应配置和浏览器账号自带的收藏同步。
3. 先只在 Chrome 创建 Floccus Local 配置，选择收藏栏，执行普通同步。确认本机服务出现版本 1，并在历史页面固定一个备份。
4. 再在 Edge 创建配置，选择收藏栏，执行普通同步。首次合并按 Floccus 的树和映射处理；相同网址出现在不同文件夹或同一侧原本存在的重复项不会做全局去重。
5. 比对两边的数量、层级和顺序。确认一致后再开启两端自动同步。原版扩展与导出的 HTML/配置继续保留，直到完成隔离测试和人工验收。

如果两端首次内容差异很大，请先在测试浏览器配置中演练；当前版本没有完整的首次导入逐项匹配向导。

## 日常同步语义

- 本地书签事件合并等待 300 毫秒，最长 1 秒；另一浏览器通过 WebSocket 收到新版本后立即拉取。
- WebSocket 每 20 秒心跳，断开后指数退避重连；启动、后台唤醒和每分钟兜底检查都会核对版本。
- 删除是正常双向变更，不使用网址并集。因此，一侧删除已同步收藏后，另一侧也会删除，不会重新添加。
- 同步事务同时校验租约、基础版本和事务 ID。租约每 10 秒续期；重复提交返回原结果，实际内容没有变化时不产生新版本。
- 响应丢失后扩展会按事务 ID 查询结果；提交前会持久化事务、预期树、缓存和映射，浏览器重启后可继续完成本地状态恢复。

## 冲突与恢复

同一条收藏的同一字段被两边改成不同值、删除与修改、文件夹删除与内部修改、不同目标的移动，以及相互矛盾的排序会触发 `E058` 并暂停该配置。服务保存发生冲突时的本机树、共享树及一个固定历史备份。

配置页面会显示冲突详情，并提供：

- “采用共享版本”：仅本次强制下载，共享版本覆盖当前浏览器的冲突更改。
- “采用当前浏览器”：仅本次强制上传，随后另一浏览器收到版本通知并下载。

当前冲突恢复按完整一侧选择，尚未实现同一次冲突中逐条混合选择。“采用共享版本”会先校验版本再下载；“采用当前浏览器”会预留租约，并将映射后的提交与冲突完成放在同一 SQLite 事务中。

每次有效提交都会保存快照。普通快照保留最近 30 天且至少 100 个版本；手动固定、迁移前和恢复前快照永久保留。历史页面先显示新增、删除、修改预览；若预览后共享版本已变化或存在活动同步租约，恢复会被拒绝。确认后将旧内容恢复为一个新版本，恢复前状态仍可再次找回。

## 回退

停止两端 Floccus Local 配置，运行 `scripts\uninstall-startup.ps1`，关闭本机服务，然后从迁移前 HTML 恢复收藏并重新启用原版 Floccus。不要删除 `%LOCALAPPDATA%\FloccusLocal`，除非已经确认不再需要历史；启动项卸载不会删除数据库。

## 开发与验证

```powershell
# 服务测试
cd local-server
npm ci
npm test

# 扩展
cd ..
npm run typecheck
npm run lint
npm run build-win
npm run package-local
```

自动浏览器测试必须使用独立 Chrome/Edge 用户数据目录，禁止对真实收藏栏运行破坏性测试。
